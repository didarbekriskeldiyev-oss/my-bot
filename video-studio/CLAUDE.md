# Video Studio — күнделікті видео монтаж

Пайдаланушы күн сайын жаңа кадрлар жібереді, мен оларды **«Асыл ине» стилінде** Reels етіп монтаждаймын.
Пайдаланушы бағдарламашы емес: қазақша (ол орысша жазса — орысша), қарапайым тілмен, қысқа түсіндір.

## Стиль (міндетті)

- Толық сипаттама: `style-base/asyl-ine/STYLE.md`, токендер: `style-base/asyl-ine/style.json`, компоненттер: `src/style/`.
- 1080×1920, 30 fps. Субтитр сөзбе-сөз шығады (Montserrat 800, ақ), әр сөйлемде 1–2 екпін:
  `accent` (mint Lora italic + сызық), `box` (жасыл қорап), `pop`. Бренд «Асыл ине» — әрқашан `box`, бір жолда.
- Тақырыптар: `ҮЛКЕН СӨЗ` + *курсив* + mint нүкте (`Title`, нөмірленген пункттерге `num: '01'`), ~әр 5–8 с.
- Спикер кадрында punch-in (1.0 ↔ 1.14) әр үтір/нүктеден кейін; B-roll ~50%+, видео B-roll-мен ашылады.
- Жаттығу сияқты кадры жоқ әрекетке — `Exercise` анимациясы бұлыңғыр B-roll үстінде.
- Соңы: 2.7–3 с жасыл `EndCard` («Асыл ине. / ШЫҒЫС МЕДИЦИНАСЫ ОРТАЛЫҒЫ / … / Деніңіз сау болсын!»).
- Музыка: `tools/make_music.py` арқылы генерациялау (интернеттен музыка алынбайды), дауыстан төмен (volume ~0.28).
  Тақырып/анимация алдында `public/whoosh.wav` (volume 0.35).
- Соңғы дыбыс: `loudnorm=I=-14:TP=-1.5` (Instagram).

## Бренд атауы мен логотип

- Атауы латынша: **Asyl Ine** (субтитрде де, карточкада да).
- Логотип қабырғадағы фотодан кесілген бөліктер: `public/brand/{asyl,needle,dots,ne,tagline}.png`
  (ақ әріптер + mint нүктелер/жазу), координаттары `src/promo/logoParts.json`.
  Анимация: `src/style/LogoAnim.tsx` (ине түседі → нүктелер айналып шығады → «Asyl»/«ne» ашылады → tagline).
- Пайдаланушы баяу видеоны ұнатпайды: сахна ≤ 3 с, әр сахнаға flash + zoom-in, кілт сөзде shake + pop,
  фонда ұшқан нүктелер, музыка ~124 BPM (`src/promo/Promo.tsx` үлгісі).

## Қаріптер (қазақ әріптері тексерілген)

`src/style/fonts.ts` → `FONTS`: Montserrat (негізгі), Geologica (тақырып), Rubik (сандар), Nunito (жұмсақ),
Lora Italic (екпін), Cormorant Italic (премиум/тілек). Барлығында Ә Ғ Қ Ң Ө Ұ Ү Һ І бар (fontTools-пен тексерілді).
Жаңа қаріп қоспас бұрын cmap-ты тексер: Jost, Manrope, Unbounded, Playfair Display, Tenor Sans, Prosto One,
El Messiri — қазақ әріптері ЖОҚ. Әр файлдың subset-і (latin / cyrillic / cyrillic-ext) кестеде нақты жазылады.
Логотип бөліктері түзетілген (1° айналдырылған + перспектива), `LogoAnim` BOX = 336,131,1763×877.

## Пайдаланушының ережелері

- Ол екі түрлі файл жібереді: **сөйлеген кадрлар** және **B-roll**.
- Камераға қарап сөйлеген кадр — негізгі кадр. **Бір жаққа қарап сөйлеген кадр** немесе **камера жерге қарап тұрған кадр** — ЗКТ: дыбысы ғана алынады, үстіне B-roll.
- Сценарий жіберсе — субтитрді **жазбада айтылған сөзбен** жаз (емлесін сценарий бойынша түзет), сценарийде жоқ бөлікті қиып таста, жазылмаған сценарий бөлігін айт.
- **B-roll-ды сақтама** (GitHub-қа да, кітапханаға да) — күн сайын жаңа кадр беріледі. Шикі видео, proxy, wav — gitignore-да.
- Музыка өзі бермейді — өзің генерацияла.

## Жұмыс тәртібі (әр жаңа видео)

1. Файлдарды `projects/pNN/broll/` ішіне көшір. Әрқайсысын тексер: ұзақтығы, бұрылысы (rotation), дыбыс RMS.
   Телефон дыбысы өте тыныш болуы мүмкін (−45 дБ): сөз бар-жоғын Whisper-мен тексер.
2. Кадрларды қара (contact sheet), B-roll каталогын жаз (`broll.md`).
3. Дыбысты тазала: `highpass=f=85,lowpass=f=9000,afftdn=nr=14:nf=-50:tn=1,loudnorm=I=-16:TP=-1.5:LRA=7`.
4. Whisper: `--model turbo --language kk --word_timestamps True --fp16 False`.
   Басын жіберіп алса — 10 с бөліктерге бөліп тану. `--initial_prompt` кейде мәтінді қайталап шығарады — сенбе.
   Түсініксіз жерді ойдан шығарма — пайдаланушыдан сұра.
5. Proxy: H.264, 1080×1920, 30 fps, `public/pNN/` (бүйірінен түсірілсе `transpose=1`).
6. План: үлгі ретінде көшір —
   - `projects/p01/plan.py` — спикер кадрлары + B-roll + ЗКТ клиптер;
   - `projects/p02/plan.py` — тек ЗКТ жазбасы + B-roll + `Exercise`;
   - `projects/p03/plan.py` + `src/promo/Promo.tsx` — кадрсыз **анимациялық промо** (Асыл ине + Kaspi тәрізді «бір экран — бір үлкен хабар/сан»,
     тегіс жасыл және күңгірт премиум фон). Kaspi логотипі/қызылы қолданылмайды. Талдау: `style-base/kaspi-reference/ANALYSIS.md`.
   Нәтиже `src/edit/pNN.json` → `src/Root.tsx`-ке `Composition` қос.
7. Тексер: әр B-roll үзіндісі клип ұзындығынан аспасын; `npx tsc --noEmit`; бірнеше `remotion still` кадр.
8. Рендер (`--concurrency=4`, фонда), сосын loudnorm −14, әр секундтан кадр алып қара.
9. Видеоны `SendUserFile` арқылы жібер; жоба файлдарын (plan.py, json, src) commit + push.
   Видео файлы GitHub-қа жіберілмейді.
