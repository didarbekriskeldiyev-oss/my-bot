# Kaspi.kz — логотип пен баннерлерді талдау (тек үлгі ретінде)

Дереккөз: пайдаланушы жіберген 6 сурет (иконка, 3 логотип нұсқасы, «Kaspi Гид» обложкасы, «0·0·24» акциясының 2 баннері).
Түстер пиксель бойынша өлшенді (±3 бірлік, JPEG сығымдауынан).

> Бұл — **стильге шабыт алу үшін** талдау. Kaspi логотипін, атауын, фирмалық қызыл түсін «Асыл ине» материалдарына
> көшіруге болмайды (тауар белгісі, клиентті шатастырады). Тек тәсілдерді аламыз: композиция, ырғақ, қарапайымдылық.

## 1. Логотип

| Бөлік | Сипаттама |
|---|---|
| Белгі (символ) | Толық шеңбер. Ішінде ақ «кесілген» екі адам сұлбасы: үлкені (ата-ана) және қолын көтерген кішісі (бала). Сызықтары түзу емес, қолмен салынғандай жұмсақ, органикалық. Негатив кеңістік тәсілі — фигуралар шеңберден ойылып алынған. |
| Сөз белгісі | «Kaspi.kz» — өте жуан (Bold/Black) гротеск, әріптері тығыз, бұрыштары сәл дөңгеленген. «Kaspi Гид» — сол қаріп, кириллицамен. |
| Компоновка | **Көлденең:** белгі сол жақта, мәтін оң жақта, белгі биіктігі ≈ бас әріптің 1.6 еселігі. **Тік:** белгі үстінде, мәтін астында, ортаға тураланған. |
| Түс нұсқалары | Ақ фонда: қызыл белгі + қара мәтін. Қызыл фонда: ақ белгі (ішіндегі фигуралар қызыл болып қалады) + ақ мәтін. Иконка: ақ фонда қызыл шеңбер. |

## 3. Баннерлер

**«0·0·24» акциясы** (0% алдын ала төлем · 0% артық төлем · 24 ай бөліп төлеу):
- Композиция: ортада, екі деңгей — жоғарыда кішкентай логотип, астында **үлкен сандар**. Сандар логотиптен ~3 есе биік.
- Бір баннер = бір хабар. Сөз жоқ дерлік — сандардың өзі ұран.
- Бөлгіштер: қызыл нұсқада жұлдызша (`0*0*24`), күңгірт нұсқада нүкте (`0·0·24`) — бір акцияның екі нұсқасы.
- Қызыл нұсқа: тегіс түс, ешқандай сурет жоқ, ақ мәтін — максималды контраст, алыстан оқылады.
- Күңгірт нұсқа: «премиум» көрініс — қою фон, жиектерде көлемді жылтыр лентлар, ортасы бос, мәтін ақ. Ортадан шетке қарай жұмсақ қызыл сәуле (vignette).
- Көп бос орын (whitespace): мәтін алаңның ~25%-ын ғана алады.

**«Kaspi Гид» обложкасы:** тегіс қызыл фон, ортада тік логотип (белгі + атау). Сервис атауы ғана — қосымша мәтін жоқ.

## 4. Стиль қағидалары (қорытынды)

1. Бір түс + ақ. Градиент, көлеңке, рамка жоқ (күңгірт премиум нұсқадан басқа).
2. Жуан, үлкен, қысқа мәтін. Ең маңызды ақпарат — сан.
3. Ортаға тураланған симметриялы композиция.
4. Логотип әрқашан бар, бірақ кішкентай — хабардан төмен иерархияда.
5. Бір акцияның «қарапайым» және «премиум» екі нұсқасы бар.

## 5. «Асыл ине»-ге қалай бейімдеуге болады

- Kaspi қызылының орнына — өз жасылыңыз `#156E5A`, екпінге mint `#78CEB7`.
- «Бір баннер — бір сан» тәсілі: `20+ жыл тәжірибе`, `5 рет`, `-20%` сияқты үлкен сан ортада, үстінде кішкентай «Асыл ине.» логотипі.
- Екі нұсқа: тегіс жасыл (Stories, жылдам акция) және күңгірт премиум (қою жасыл фон + жұмсақ жарық).
- Видеода: соңғы карточка мен тақырыптар осы минималды стильге жақын — жалғастыруға болады.

## 6. Талданбаған нәрселер

- **Анимация:** суреттерде қозғалыс жоқ. Логотип анимациясын, баннер ауысуларын, роликтерді талдау үшін экран жазбасы (видео) керек.
- Kaspi-дің ресми брендбугы ашық жарияланбаған — қаріп атауы белгісіз.
